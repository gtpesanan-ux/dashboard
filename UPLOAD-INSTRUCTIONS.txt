PT DIGDAYA — GITHUB WEB UPLOAD PACKAGE

Paket ini HANYA mengubah pembagian folder upload. Isi HTML, aset, dan file website tidak diedit.

Urutan upload yang disarankan:
1. Upload isi 01_ROOT_BATCH_1 ke ROOT repository, lalu commit.
2. Upload isi 02_ROOT_BATCH_2 ke ROOT repository, lalu commit.
3. Upload isi 03_ROOT_BATCH_3 ke ROOT repository, lalu commit.
4. Upload isi folder assets di 04_ASSET_BATCH_1 ke folder /assets repository, lalu commit.
5. Lakukan hal yang sama untuk 05_ASSET_BATCH_2, 06_ASSET_BATCH_3, 07_ASSET_BATCH_4, dan 08_ASSET_BATCH_5.

PENTING:
- JANGAN upload nama folder batch sebagai bagian dari URL website. Yang digabung adalah ISINYA.
- Semua ROOT_BATCH bermuara ke root repository.
- Semua ASSET_BATCH/assets bermuara ke satu folder repository: /assets/.
- Tidak ada dashboard.html dan tidak dibuat dashboard.html.
- Jangan rename file ketika upload.
- Jika GitHub menolak banyak file dalam satu commit, commit satu batch per langkah sesuai urutan di atas.
